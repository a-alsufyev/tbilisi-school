# AI-ассистент подбора школ

Диалог на странице `/{lang}/assistant` (`lang` ∈ `en | ru | ge | de`). Пользователь пишет, какую школу ищет — одним условием или несколькими сразу. Ассистент отвечает коротким саммари и карточками школ из каталога.

Пункт «Ассистент» есть в шапке. История диалога хранится в этой вкладке браузера: переход на карточку школы или в другой раздел её не стирает, обновление страницы тоже. На сервер она уходит с каждым сообщением и в базе не хранится. Новая вкладка начинает диалог заново. Неотправленный черновик сохраняется вместе с диалогом.

Кнопка «Очистить чат» стирает сообщения, карточки, таблицу сравнения и черновик, включая сохранённую копию вкладки. Пока диалог пуст, кнопка неактивна. Если очистить чат, пока ответ ещё в пути, запоздавший ответ в диалог не попадает.

Общая схема приложения — в [architecture.md](./architecture.md).

## Что делает ассистент

Подбирает школы по полям каталога:

- язык обучения;
- программа;
- цена;
- район Тбилиси.

Несколько условий соединяются через «и»: «англоязычные в Сабуртало» — школа должна подходить по всем названным параметрам. Уточнение вроде «только IB» или «а подешевле» продолжает тот же диалог: модель повторяет прежние условия, которые пользователь не отменил, и добавляет новые.

Приветствие и вопрос «чем ты полезен» не запускают поиск. Если условий нет, ассистент спрашивает, что важно: язык, программа, район или бюджет.

Модель не выбирает школы сама и не выдумывает названия, цены и программы. Она только вызывает инструмент с параметрами. Список карточек — это результат фильтра в коде.

## Как выглядит ответ

Текст — саммари на языке последней реплики пользователя (если язык неясен, берётся язык страницы).

Подбор: два–четыре предложения про набор целиком (один язык и двуязычные пары вроде `RU/EN` и `GE/EN`, разброс цен, программы). Отдельные школы в тексте не перечисляются. Под текстом — карточки, по две в ряд.

Название на карточке и в заголовке колонки сравнения — основное имя школы (`name_locale`), не перевод на язык страницы. Если основное имя английское, на русской странице ассистента оно остаётся английским.

Сравнение: если пользователь просит сравнить школы, модель вызывает `compare_schools` и передаёт от 2 до 4 имён или slug. Больше четырёх за один раз не сравнивается. Под коротким текстом о различиях страница рисует таблицу: языки, программа, цена, район, адрес, сайт. Заголовки колонок — ссылки на карточки школ. Карточки в этом ответе не дублируются.

После ответа страница прокручивается к началу сообщения.

Если ничего не нашлось, карточек нет: текст говорит об этом и предлагает ослабить условие.

## Поток запроса

```
Страница
  POST /api/assistant  { locale, messages }
        │
        ▼
Express
  ├── проверка тела и лимита по IP
  ├── listSchools() из PostgreSQL
  └── Chat Completions (gpt-4o-mini по умолчанию)
        │
        │  tool call search_schools
        ▼
Фильтр в коде (src/lib/school-filters.ts)
        │
        ▼
Второй вызов модели — только саммари по уже отфильтрованным школам
        │
        ▼
{ reply, schools }
```

Ключ OpenAI остаётся на сервере. В браузер уходит только текст и карточки.

Если модель не вызвала инструмент, `schools` пустой, а `reply` — её текстовый ответ.

## Инструмент `search_schools`

| Параметр | Смысл |
|---|---|
| `languages` | Коды `GE`, `EN`, `RU`, `DE`, `FR`. Школа должна включать каждый переданный код. «Англоязычные» — это `["EN"]`: подходит и `EN`, и `EN/GE`. |
| `program` | Короткое слово: IB, British, American, national, German, Finnish, private, alternative, а также слова из поля программы в каталоге (`Cambridge`). Сравнение без учёта регистра, с синонимами (`US` → американская, `национальная` и т.п.). Одна опечатка программу не находит: ассистент переспрашивает. Опечатка в самих данных правится в базе. |
| `district` | Один из десяти районов: `saburtalo`, `vake`, `mtatsminda`, `krtsanisi`, `isani`, `samgori`, `chughureti`, `didube`, `nadzaladevi`, `gldani`. Принимаются и названия на ru/en/ge (`Сабуртало`, `საბურთალო`). «Старый город» — это `mtatsminda`. |
| `area` | Приблизительная часть города, не один район: `north`, `south`, `center`, `west`, `east`, `rightBank`, `leftBank`. Если переданы и `district`, и `area`, остаётся район. |
| `minPrice` / `maxPrice` | `{ amount, currency, period }`. Валюта: `USD`, `EUR`, `GEL`. Период: `year` или `month`. Ставится только если пользователь назвал бюджет. |

Инструмент `compare_schools` принимает `schools`: массив из 2–4 имён или slug. Совпадение идёт по slug, затем по точному имени на любом языке интерфейса, затем по вхождению в имя. Лишние имена отбрасываются. Если нашлось меньше двух школ, таблицы нет.

Если в запросе слово отличается на одну букву от программы, языка, района или названия школы из каталога, поиск не запускается и карточек нет. Ассистент спрашивает, это ли имелось в виду. После «да» ищется уже исправленная формулировка, после «нет» просит написать запрос заново. «Не севере» по-прежнему считается севером и не переспрашивается.

### Район

Отдельного поля в базе нет. Район считается по координатам школы: точка проверяется на попадание в упрощённый полигон в `src/lib/districts.ts`.

Границы приблизительные: школа на стыке районов может попасть в соседний. Цхнети, Мцхета и другие точки вне всех полигонов в выборку по району не входят. Если остальные условия у них сошлись, модель может одним разом сказать, что часть школ лежит за пределами этих районов. В карточки они не попадают.

Фраза без названия района («на севере», «в центре», «на левом берегу») становится `area`. Код раскрывает её в фиксированный набор районов:

- север — Глдани, Надзаладеви, Дидубе;
- юг — Крцаниси;
- центр — Мтацминда и Чугурети, без Ваке и Сабуртало;
- запад — Ваке и Сабуртало;
- восток — Исани и Самгори, без Глдани;
- правый берег Куры — Сабуртало, Ваке, Мтацминда, Дидубе, Надзаладеви;
- левый берег — Чугурети, Исани, Самгори, Крцаниси, Глдани.

Саммари называет эти районы. Новое место в следующей реплике заменяет прежнее, а не добавляется к нему. Незнакомое место по-прежнему не даёт карточек.

### Цена

Поле `cost` — свободный текст (`10000 USD`, `850 GEL/mon`, `5000-6500 EUR`). Числовой колонки нет. Рядом хранится `cost_status`: `official`, `approximate` или `unknown`. В карточке и в таблице сравнения рядом с суммой написано, официальная она или ориентировочная. `unknown` означает, что суммы нет: показывается «нет информации», а фильтр по бюджету такую школу не отсекает.

Парсер вытаскивает числа, валюту и пометку «в месяц» (`/mon`, `/мес`). Месячную цену приводит к году умножением на 10. У диапазона верхняя граница сравнивается с потолком пользователя, нижняя — с минимумом.

Валюты между собой не пересчитываются. Если валюта в карточке не совпала с запросом или строку не разобрать, школа остаётся в выборке, а саммари один раз говорит, что часть цен строго сравнить нельзя.

## API

`POST /api/assistant`

Тело:

```json
{
  "locale": "ru",
  "messages": [
    { "role": "user", "content": "англоязычные школы в Сабуртало" }
  ]
}
```

`messages` — только роли `user` и `assistant`. Последнее сообщение должно быть от пользователя. Не больше 12 сообщений, каждое до 2000 символов.

Ответ:

```json
{
  "reply": "Краткое саммари набора.",
  "schools": []
}
```

`schools` — тот же вид, что у `GET /api/schools`, плюс `district` (`saburtalo` и т.д. или `null`). При сравнении `schools` пустой, а найденные школы лежат в `comparison` (от 2 до 4 элементов, те же поля). Если сравнения нет, `comparison` равен `null`.

| Код | `error` | Когда |
|---|---|---|
| 400 | `invalid_request` | Пустое, слишком длинное или неправильно собранное тело |
| 429 | `rate_limited` | Больше 30 запросов в час с одного IP |
| 502 | `assistant_failed` | Сбой OpenAI. Текст ответа провайдера клиенту не отдаётся |
| 503 | `assistant_unavailable` | Нет `OPENAI_API_KEY` или ключ отклонён |

Лимит считается в памяти процесса (`src/lib/assistant-rate.ts`) и сбрасывается при перезапуске.

## Настройки

В `.env`, читаются при старте сервера:

| Переменная | Назначение |
|---|---|
| `OPENAI_API_KEY` | Ключ. Без него страница показывает, что ассистент не настроен |
| `OPENAI_MODEL` | Модель. По умолчанию `gpt-4o-mini` |

После правки `.env` сервер нужно перезапустить.
